# EMsongbook — Erick & Leandro

Aplicação web instalável (PWA), gratuita e sem anúncios, para organizar letras e repertórios.

## Publicar no GitHub Pages
1. Envie `index.html`, `manifest.webmanifest`, `sw.js` e `icon.svg` para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
5. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

## Dados e privacidade
- Letras, repertórios e seleções são salvos no armazenamento local do navegador do dispositivo.
- Os arquivos das músicas não são enviados ao GitHub.
- Use a área **Backup** para exportar e importar os dados.
- Para transferir músicas do protótipo anterior, exporte o JSON no protótipo e use **Backup → Importar o backup do protótipo** nesta versão.
- Guarde backups em local seguro. Limpar os dados do navegador pode apagar as músicas locais.

## Observação
O aplicativo é gratuito e não exige servidor pago, domínio próprio ou assinatura. O GitHub Pages hospeda os arquivos estáticos publicamente; não coloque letras protegidas por direitos autorais no repositório.
